# ADR-002: Telegram Bot Framework Selection (aiogram 3)

## Status
Accepted

## Context
Требуется современный, асинхронный фреймворк для взаимодействия с Telegram Bot API, поддерживающий работу в личных сообщениях с инлайн-клавиатурами, FSM, колбэками, а также отправку медиапостов в каналы.

## Decision
Мы используем **aiogram 3.x**:
1. Полноценная поддержка современного асинхронного Python (asyncio).
2. Развитая система фильтров, мидлварей (для проверки прав доступа) и роутеров.
3. Удобная работа с инлайн-кнопками и колбэками модерации.
4. Отличная поддержка отправки `InputFile` и форматированного текста (MarkdownV2 / HTML).

## Consequences
- **Плюсы:** Высокая производительность, модульность через `Router`, надежная типизация.
- **Минусы:** Более строгие требования к сигнатурам хэндлеров по сравнению с синхронными библиотеками.
