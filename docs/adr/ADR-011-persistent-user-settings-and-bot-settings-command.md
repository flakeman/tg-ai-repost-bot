# ADR-011: Персистентное хранилище настроек и интерактивная команда /settings

## Статус
Принято (Accepted)

## Контекст
1. Ранее выбранный пользователем стиль изложения (тон рерайта) сохранялся в памяти процесса в словаре `_user_tones: dict[int, Tone]`.
2. При перезапусках сервиса (PM2 restart, деплой, сбои) пользовательские настройки сбрасывались на значение по умолчанию (`dynamic`).
3. Пользователю требовался интерактивный интерфейс управления настройками прямо в Telegram без ручной правки `.env` на сервере:
   - Выбор активного тона рерайта (`Tone`: dynamic, casual, formal, humorous, analytical).
   - Выбор или просмотр активной модели генерации картинок (`dalle_model`: gpt-image-2, gpt-image-2.5-flare, gpt-image-1, mock).
   - Просмотр и управление целевым каналом (`channel_id`) и постоянными хэштегами (`channel_hashtags`).

## Решение
1. **Слой БД (Domain & Infrastructure):**
   - Добавить таблицу `user_settings` в SQLite:
     ```sql
     CREATE TABLE IF NOT EXISTS user_settings (
         user_id INTEGER PRIMARY KEY,
         tone TEXT NOT NULL DEFAULT 'dynamic',
         image_model TEXT,
         updated_at TEXT NOT NULL
     );
     ```
   - Добавить доменную модель `UserSettings` и методы в `ISettingsRepository` / `SqliteSettingsRepository`:
     `get_user_settings(user_id) -> UserSettings`, `save_user_settings(settings)`.
2. **Интерактивный UI в Telegram (Presentation):**
   - Реализовать команду `/settings`.
   - Главное меню настроек с инлайн-кнопками:
     - 🎭 **Стиль рерайта** (выбор текущего тона с галочкой `✓`).
     - 🎨 **Модель генерации картинок** (переключение между моделями).
     - 📢 **Канал публикации** (информация о текущем канале и проверка прав).
     - 🏷️ **Постоянные хэштеги канала** (список текущих хэштегов).
   - При клике на кнопки настройки мгновенно обновляются в SQLite и сохраняются между сессиями и перезапусками.

## Последствия
- Положительные:
  - Настройки каждого админа сохраняются персистентно и не теряются при перезапусках.
  - Удобное управление ключевыми параметрами конвейера через интерфейс Telegram.
- Ограничения:
  - Глобальные системные токены (API ключи) по соображениям безопасности остаются в защищенном `.env`.
