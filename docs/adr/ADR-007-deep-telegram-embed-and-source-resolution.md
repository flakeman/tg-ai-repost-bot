# ADR-007: Deep Telegram Embed & External Source Link Resolution

## Status
Accepted

## Context
Пользователи часто отправляют боту ссылки на посты в Telegram (`https://t.me/<channel>/<id>`) или пересылают сообщения из каналов. Страницы Telegram при обычном HTTP-запросе отдают короткий сниппет-заглушку (виджет) без полного текста первоисточника (например, статьи на Хабре, TechCrunch или VC). Это приводило к тому, что нейросеть делала рерайт только по двум предложениям тизера, а ссылка на первоисточник терялась.

## Decision
1. В экстракторе `TrafilaturaExtractor` реализовать метод `extract_with_url(url: str) -> Tuple[str, str, str]`, возвращающий кортеж `(title, body, final_source_url)` при сохранении обратной совместимости метода `extract(url)`.
2. При обнаружении ссылки на Telegram-пост (`t.me/<channel>/<msg_id>`) загружать публичный встраиваемый виджет `?embed=1`.
3. Парсить блок сообщения `.tgme_widget_message_text` с помощью BeautifulSoup и извлекать все внешние гиперссылки (исключая внутренние домены Telegram).
4. Если найдена внешняя ссылка на первоисточник (например, `https://habr.com/...`), рекурсивно переходить по ней и выкачивать полноценный текст статьи.
5. В `handlers.py` реализовать парсинг скрытых гиперссылок из `message.entities` (`text_link`) и пересланных метаданных `message.forward_origin`, передавая чистый URL без служебных символов (`\n`, `\r`, пробелы).
6. Добавлять кликабельную ссылку `🔗 Источник` в сформированный черновик поста `PostContent.render_post()`.

## Consequences
- **Плюсы:** 100% извлечение полной фактуры из первоисточника по одной ссылке на Telegram-пост, автоматическое указание авторства и источника в канале.
- **Минусы:** Дополнительный HTTP-запрос к первоисточнику (~0.5 сек).
