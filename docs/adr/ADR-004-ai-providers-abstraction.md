# ADR-004: Unified AI Providers Abstraction & Fallback Pattern

## Status
Accepted

## Context
Для рерайта планируется использовать современные экономичные модели (DeepSeek V3 / Chat) или OpenAI GPT-4o-mini, а для изображений — DALL-E 3 или Flux API. Сторонние API подвержены сбоям, исчерпанию баланса или сетевым задержкам. Жесткая привязка к одному API делает бот нестабильным.

## Decision
Мы создаем абстрактные порты в `src/domain/interfaces.py`:
- `ILLMRewriter`: абстрактный класс с методом `rewrite(raw_text: str, tone: Tone) -> PostContent`.
- `IImageGenerator`: абстрактный класс с методом `generate(prompt: str) -> ImageAsset`.
- `CompositeRewriter` с поддержкой автоматического fallback: если вызов первичного провайдера (например, DeepSeek) завершается ошибкой или таймаутом, запрос перенаправляется на вторичный провайдер (например, OpenAI).
- Graceful degradation для изображений: если генерация картинки терпит неудачу, конвейер не останавливается с ошибкой, а формирует черновик без фото (или с локальной заглушкой) и предупреждает автора.

## Consequences
- **Плюсы:** Легкая смена моделей, отказоустойчивость, предсказуемая стоимость, возможность использовать локальные моки в тестах.
- **Минусы:** Необходимость поддержки универсального формата промптов и ответов.
